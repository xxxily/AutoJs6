IPC#

ipc 模块提供进程内多脚本消息总线. 多个正在运行的 AutoJs6 脚本可通过 topic 发布、订阅、查询收件箱或使用 request/reply 语义通信, 不需要手写 Android Broadcast 细节.

消息对象包含 id, topic, payload, sender, replyTo, correlationId, timestamp.

[m] publish#

publish(topic, payload?, options?)#

发布消息并返回消息对象. options.replyTo 和 options.correlationId 可用于关联响应.

ipc.publish('jobs.next', { id: 1, name: 'sync' });

[m] subscribe#

subscribe(topic, callback)#

订阅 topic, 返回订阅 ID. topic 为 * 时接收全部消息. 脚本退出时会自动清理当前脚本创建的订阅.

let sub = ipc.subscribe('jobs.next', function (msg) {
    log(msg.payload.name);
});

ipc.unsubscribe(sub);

[m] messages#

messages(topic?, options?)#

查询最近收件箱消息. options.limit 控制数量, options.clear 为 true 时查询后删除匹配消息.

let recent = ipc.messages('jobs.next', { limit: 10 });

[m] request#

request(topic, payload?, options?)#

发布带 replyTo 的请求消息. 未指定 replyTo 时自动生成回复 topic.

let req = ipc.request('worker.run', { id: 7 }, { replyTo: 'worker.reply' });

[m] reply#

reply(message, payload?)#

按消息对象中的 replyTo 回复, 并自动把原消息 id 写入 correlationId.

ipc.subscribe('worker.run', function (msg) {
    ipc.reply(msg, { ok: true });
});
