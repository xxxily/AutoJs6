Shizuku#

此章节待补充或完善...

Marked by SuperMonster003 on Oct 30, 2023.

通过 Shizuku 可以获得 ADB 特权并使用系统 API.

使用 Shizuku 需满足以下全部条件

  • 设备已安装 Shizuku 应用 (版本不低于 11)
  • Shizuku 服务已启动 (参阅 Shizuku 用户手册)
  • AutoJs6 首页抽屉开启 Shizuku 权限开关

6.7.3+ 项目脚本可在 project.json 的 capabilities 声明 shizuku、root、write_secure_settings、install_apk 或 uninstall_apk. 未声明时会按 riskPolicy / privilegedPolicy 提示或拒绝, Shizuku 命令和结构化特权 API 会写入 capabilities.audit() 审计记录.

shizuku

[@] shizuku#

shizuku 可作为全局对象使用:

typeof shizuku; // "function"
typeof shizuku.execCommand; // "function"
typeof shizuku.app.forceStop; // "function"
typeof shizuku.settings.secure.put; // "function"

结构化特权 API#

6.7.3

常见 pm、am、settings、input 场景应优先使用结构化 API, 不需要手写 shell 字符串. 结构化调用会返回包含 ok、code、result、error、backend、riskLevel、capabilities、auditId 和 data 的结果对象, 并写入可导出的审计记录.

options 可包含 backend / by ("auto"、"shizuku"、"root")、userId、replace、keepData. 默认 auto 会优先使用 Shizuku, 不可用时回退 Root; 普通 shell 只作为少量只读查询的内部降级实现.

/* 高风险: 强制停止应用. */
let stopped = shizuku.app.forceStop("com.example.target");
log(stopped.ok, stopped.riskLevel, stopped.capabilities);

/* 高风险: 授予权限. */
shizuku.app.grantPermission(autojs.packageName, "android.permission.WRITE_SECURE_SETTINGS");

/* 高风险: 修改安全设置. */
shizuku.settings.secure.put(
    "enabled_accessibility_services",
    `${autojs.packageName}/org.autojs.autojs.core.accessibility.AccessibilityServiceUsher`,
);

/* 高风险: 与无障碍手势不同, 这里走 input 注入后端. */
shizuku.input.injectTap(100, 120);

/* 导出审计记录. 审计记录包含操作、目标、后端、风险级别和能力声明, 不暴露内部 shell 命令. */
log(shizuku.audit.exportJson());

shizuku.app#

应用管理 API: forceStop(packageName[, options])#, clearData(packageName[, options])#, enableComponent(component[, options]), disableComponent(component[, options]), setComponentEnabled(component, enabled[, options]), grantPermission(packageName, permission[, options])#, revokePermission(packageName, permission[, options])#, install(apkPath[, options])#, uninstall(packageName[, options])#.

shizuku.settings#

设置 API: get(namespace, key[, options])#, put(namespace, key, value[, options])#, delete(namespace, key[, options])#. 也可使用 shizuku.settings.secure.get、shizuku.settings.global.put、shizuku.settings.system.delete 等命名空间快捷对象.

shizuku.package#

包管理查询 API: info(packageName[, options])#, apkPath(packageName[, options])#, permissionState(packageName, permission[, options])#.

shizuku.input#

输入注入 API: injectTap(x, y[, options])#, injectSwipe(x1, y1, x2, y2[, duration][, options])#, keyEvent(keyCode[, options])#. 这些方法通过系统 input 后端注入事件, 与无障碍 click / swipe 手势不同.

shizuku.process#

进程 API: list([options])#, kill(pidOrPackage[, options])#, foreground([options])#.

shizuku.users#

用户/多开 API: listUsers([options])#, currentUser([options])#, runAsUser(userId, operation, ...args)#, dualApps([packageName][, options])#. runAsUser 只接受受支持的结构化操作名, 不接受任意 shell 字符串.

shizuku.audit#

审计 API: list()#, clear(), exportJson()#, metadata(). shizuku.operations# 会返回每个结构化操作的能力声明和风险级别.

shizuku(cmd)#

6.4.0 Overload 1/2

  • cmd { string } - 待执行命令
  • returns { ShellResult } - Shell 结果

使用 Shizuku 执行命令.

/* 模拟返回键. */
shizuku('input keyevent 4');
shizuku(`input keyevent ${KeyEvent.KEYCODE_BACK}`); /* 同上. */

/* 模拟电源键. */
shizuku('input keyevent 26');
shizuku(`input keyevent ${KeyEvent.KEYCODE_POWER}`); /* 同上. */

/* 点击屏幕坐标 (100, 120), 新脚本优先使用结构化 API. */
shizuku.input.injectTap(100, 120);

/* 授予 AutoJs6 "修改安全设置" 权限, 高风险操作会产生审计记录. */
shizuku.app.grantPermission(autojs.packageName, "android.permission.WRITE_SECURE_SETTINGS");

/* 获取当前时间. execCommand 仅保留为兼容入口. */
console.log(shizuku('date').result.trim());

使用 shizuku 启用 AutoJs6 无障碍服务 (共计 4 步):


/* [ 1. 获取无障碍服务列表, 列表是一个字符串, 不同无障碍服务之间以 ":" 分隔. ] */
let services = shizuku.settings.secure.get('enabled_accessibility_services').data.value; /* 结尾 "\n" 已由结构化 API 去除. */

/* [ 2. 确保无障碍服务列表中不存在 AutoJs6. ] */
let servicesWithoutAutoJs6 = services
    .split(':') /* 通过 ":" 分割, 获取无障碍服务数组. */
    .filter(it => !it.startsWith(`${autojs.packageName}/`)) /* 过滤可能的 AutoJs6 无障碍服务, 避免重复. */
    .join(':'); /* 重新组合过滤后的无障碍服务, 生成列表. */

/* [ 3. 无障碍服务列表中加入 AutoJs6. ] */
let servicesWithAutoJs6 = (() => {
    /* 无障碍服务格式: "包名/服务类名" */
    let serviceAutoJs6 = `${autojs.packageName}/${org.autojs.autojs.core.accessibility.AccessibilityServiceUsher.class.getName()}`;
    return servicesWithoutAutoJs6.length > 0 ? `${servicesWithoutAutoJs6}:${serviceAutoJs6}` : serviceAutoJs6;
})();

/* [ 4. 通过覆盖系统的无障碍服务列表, 使 AutoJs6 无障碍服务生效. ] */
shizuku.settings.secure.put('enabled_accessibility_services', servicesWithAutoJs6);

/* 需特别留意, 如果只写入 AutoJs6 包名/服务类名, 系统将只启用 AutoJs6 无障碍服务, 其他应用的无障碍服务将全部关闭. */

/* 另, 禁用 AutoJs6 无障碍服务, 只需执行上述示例的 [ 1, 2, 4 ] 步骤即可. */

shizuku(cmdList)#

6.4.0 Overload 2/2

  • cmdList { string[] } - 待执行的多行命令
  • returns { ShellResult } - Shell 结果

使用 Shizuku 一次性执行多行命令, 每行命令对应 cmdList 数组中的一个元素.

shizuku([ 'cmd-a', 'cmd-b', 'cmd-c' ]);
shizuku('cmd-a\ncmd-b\ncmd-c'); /* 同上. */
