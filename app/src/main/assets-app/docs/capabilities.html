Capabilities - 能力状态中心

capabilities 模块用于在脚本运行前或运行中检查 AutoJs6 能力状态, 覆盖无障碍、截图、悬浮窗、通知、存储、网络、Root、Shizuku、Shell、UsageStats、WriteSettings、WriteSecureSettings、精确闹钟、后台运行、电池优化、开机启动、安装/卸载 APK、短信、联系人、电话、相机、录音和定位等核心能力。

每个能力返回 available、requestable、missing、blocked 或 unsupported 状态。

项目脚本可在 project.json 中声明 capabilities、pluginDependencies、riskPolicy、networkPolicy、filePolicy 和 privilegedPolicy。运行时高风险 API 会复用这份清单做守卫和审计, 打包 APK 时也会复用同一份清单做预检和权限映射。

capabilities.check(ids)

检查一个或多个能力 ID/API 名称。未传入参数时返回全部能力状态。

let checks = capabilities.check(["accessibility", "screen_capture", "shizuku"]);
checks.forEach(item => log(item.id + ": " + item.status));

capabilities.ensure(ids, options)

检查能力并可按需打开系统授权入口。options.request 为 true 时会尝试发起可请求能力的授权流程, options.timeout 用于等待状态变为可用。

let result = capabilities.ensure(["accessibility"], { request: true, timeout: 10000 });
if (!result[0].available) toastLog(result[0].requestHint);

capabilities.explain(idOrApi)

解释能力 ID 或 AutoJs6 API 对应的权限、服务和风险信息。

let info = capabilities.explain("images.captureScreen");
log(info.name + ": " + info.description);

capabilities.scan(script)

对脚本文本做静态扫描, 返回可能涉及的能力定义。编辑器运行前预检和 AI 风险校验会使用同一份能力图谱。

let caps = capabilities.scan("requestScreenCapture(); click('OK');");
log(caps.map(c => c.id).join(", "));

capabilities.list()

返回当前 AutoJs6 版本内置的能力定义清单。

log(capabilities.list().length);

capabilities.manifest()

返回当前脚本所属项目的能力清单和策略。非项目脚本会返回 available: false。

let manifest = capabilities.manifest();
log(manifest.capabilities.join(", "));
log(manifest.riskPolicy.undeclared);

项目打包预检与 inrt 诊断

project.json 的 capabilities 会在项目打包前映射 Android permissions、前台服务类型和 inrt 设置页需要项。单文件打包会根据脚本静态扫描自动补入推断能力; 项目打包遇到未声明的危险能力会阻断并提示。

打包预检会检查主脚本是否存在、常见相对资源引用是否存在、assets 声明是否有效、plugins.load() 使用的插件是否已写入 pluginDependencies, 并提示未由能力清单解释的高风险 Android 权限。

{
  "name": "能力打包示例",
  "main": "main.js",
  "capabilities": ["screen_capture", "overlay", "notifications"],
  "pluginDependencies": ["org.autojs.autojs.plugin.ocr"],
  "riskPolicy": {
    "undeclared": "prompt",
    "high": "prompt",
    "critical": "reject",
    "rememberAllowed": true
  }
}

打包成功后, APK 会内置 assets/project/build-diagnostics.json, 记录能力映射、预检警告、插件依赖和构建摘要。inrt 首次启动会根据能力状态提示缺失项并打开设置页; 运行失败时可在日志页菜单复制最小诊断 JSON, 其中包含项目配置、构建诊断和异常信息。

capabilities.remember(ids, action)

为当前项目记住能力授权选择。action 可为 allow 或 reject, 仅影响当前项目键。

capabilities.remember(["shizuku", "shell"], "allow");

capabilities.audit()

查看最近高风险能力调用记录, 覆盖 shell、Root/Shizuku、文件删除/覆盖、短信/联系人/电话、安装/卸载和插件调用入口。

capabilities.audit().forEach(item => {
    log(item.api + " " + item.action + " " + item.target);
});

capabilities.clearAudit()

清空当前进程内的能力审计记录。

capabilities.clearAudit();
