屏幕感知 (Vision)#

vision 模块将无障碍节点、OCR 文本块、图像模板结果、颜色/区域特征和当前 App/Activity 归一化为统一目标对象。

默认来源为 a11y+ocr。无障碍节点命中时优先给出稳定 selector 和 auto.stableClick 建议; OCR 命中但无对应无障碍节点时, 使用 OCR bounds 作为坐标兜底。

VisionTarget#

融合目标对象常用字段:

  • source / sources: 命中来源, 如 a11y+ocr、ocr、a11y+image.
  • confidence: 0..1 置信度, 多来源命中会提升置信度。
  • bounds: { left, top, right, bottom, width, height, centerX, centerY }.
  • suggestedAction: { type, x, y, api, reason }, 用于选择 auto.stableClick、click 或 swipe.
  • currentPackage / currentActivity: 当前 App 和 Activity。
  • selector: 来源于无障碍快照的 selector 候选。
  • explanation: 融合解释, 包含 OCR fallback、多来源合并等原因。

VisionOptions#

  • sources / source: 字符串或数组, 支持 "a11y+ocr"、"ocr"、"a11y,image"、"all".
  • region: [x, y, width, height] 或 bounds 对象, 限制感知区域。
  • interval: observe 和 waitForScene 的采样间隔, 单位毫秒。
  • frameTimeout: OCR 截图帧超时, 单位毫秒。
  • maxTargets: 返回目标数量上限。
  • minConfidence: 最低置信度阈值。

[m] targets#

targets(options?)#

  • [ options ] { Object } - 感知选项。
  • returns { Object[] } - 融合后的目标列表。
let targets = vision.targets({
    sources: 'a11y+ocr',
    region: [0, 0, device.width, device.height],
    minConfidence: 0.35,
});
console.log(targets[0].source, targets[0].bounds, targets[0].suggestedAction);

[m] findText#

findText(text, options?)#

  • text { string } - 待查找文本。
  • [ options ] { Object } - 支持 source/sources、region、exact、ignoreCase 等。
  • returns { Object | null } - 最匹配目标。
let ok = vision.findText('确定', { source: 'ocr+a11y' });
if (ok) {
    console.log(ok.confidence, ok.explanation);
}

[m] findButton#

findButton(text, options?)#

  • text { string } - 按钮文本。
  • [ options ] { Object } - 感知选项。
  • returns { Object | null } - 可点击或可坐标兜底的目标。
let login = vision.findButton('登录');
if (login) {
    let action = login.suggestedAction;
    click(action.x, action.y);
}

[m] observe#

observe(options?)#

  • [ options ] { Object } - 支持 interval、sources、region 等。
  • returns { VisionObservation } - 观察句柄。

观察句柄提供 latest()、next()、targets()、metrics()、close()、isClosed()。当启用 OCR 来源时会复用 images.openCaptureSession({ preset: 'ocr' }) 风格的帧缓存与节流。

let observer = vision.observe({ sources: 'a11y+ocr', interval: 600 });
try {
    let sample = observer.next();
    console.log(sample.targetCount, observer.metrics());
} finally {
    observer.close();
}

[m] waitForScene#

waitForScene(scene, options?)#

  • scene { Object | string } - 场景规则, 可包含 name、texts、buttons、targets、all。
  • [ options ] { Object } - 支持 timeout、interval、sources、region 等。
  • returns { Object } - { ok, matched, missing, targets, currentPackage, currentActivity }.
let scene = vision.waitForScene({
    name: 'login',
    texts: ['账号登录'],
    buttons: ['登录'],
}, { timeout: 8000, interval: 500, sources: 'a11y+ocr' });

if (!scene.ok) {
    console.warn(scene.missing);
}

summary()#
