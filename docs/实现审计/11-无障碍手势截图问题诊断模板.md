## 问题分类

| 类型 | 典型现象 | 首查路径 | 判断标准 | 推荐处理 |
| --- | --- | --- | --- | --- |
| 节点获取失败 | `text()`/`id()` 找不到控件; 布局分析无节点 | `AccessibilityBridge.java`; `UiSelector`; 目标 App 节点 dump | 目标 App 不暴露节点、WebView/Flutter/Lynx 自绘、系统限制 | 文档说明限制; 尝试 OCR/图像/坐标 fallback; 不直接改选择器语义 |
| 节点动作失败 | 能找到节点但 `click()`/`setText()` 无效 | `AccessibilityBridgeImpl.java`; `GlobalActionAutomator.kt`; `AccessibilityTool.kt` | 节点不可点击/不可编辑, 或目标 App 拦截无障碍动作 | 优先父节点点击、paste/input fallback; 记录目标 App 限制 |
| 坐标动作失败 | `click(x,y)`/`swipe()` 无效或坐标错位 | `GlobalActionAutomator.kt`; `ScreenMetrics.kt`; `RootAutomator.java` | ROM 阻断 dispatchGesture、旋转/缩放映射错误、Root raw 坐标未映射 | 先验证 `scaleX/scaleY` 和旋转; 再考虑 Shell/Root fallback |
| 截图失败 | `requestScreenCapture()` 被拒、阻塞、崩溃 | `ScreenCaptureRequester.java`; `ScreenCapturer.java`; FGS/MediaProjection | Android 14+ 前台服务要求、ROM 弹窗限制、inrt manifest 权限缺失 | 记录权限弹窗; 检查 FGS type 和 manifest; 打包 app/inrt 双测 |
| 后台失败 | 熄屏/后台后任务不运行或无障碍掉线 | `TimedTaskScheduler.kt`; `BootCompletedReceiver.kt`; `AccessibilityService.kt` | OEM 后台限制、电池优化、无障碍服务被回收 | 文档说明系统限制; 引导自启动/电池白名单; 增加健康检查 |

## fallback 判断标准

| fallback | 适用条件 | 不适用条件 | 风险 |
| --- | --- | --- | --- |
| OCR 文本点击 | 节点缺失但屏幕文字稳定可见 | 字体/语言/缩放变化大; 文字重复多 | 需要截图授权; 性能和准确率不稳定 |
| 图像模板 | 图标稳定、无文字或节点不可见 | 分辨率/主题/暗色模式变化大 | 需要截图授权; 模板维护成本高 |
| 坐标点击 | UI 固定、设备单一、无节点/OCR 兜底 | 多设备/旋转/动态布局 | 易误触, 必须二次确认或限定设备 |
| Shell input | 无障碍动作被 ROM 阻断, shell 可用 | 无 adb/root/shizuku 权限 | 高权限, 需要风险提示 |
| Root/Shizuku | 需要系统级输入或设置修改 | 用户没有授权或目标设备不支持 | 高风险, 必须显式授权和日志脱敏 |

## 复现脚本骨架

```javascript
"use strict";

console.show();
console.log("device:", device.brand, device.model, device.sdkInt);
console.log("screen:", device.width, device.height);
console.log("pkg:", currentPackage());
console.log("activity:", currentActivity());

if (!auto.service) {
  console.warn("Accessibility service is not enabled");
} else {
  var node = textMatches(/.*/).findOnce(1000);
  console.log("first text node:", node);
}

var ENABLE_SCREENSHOT = false;
if (ENABLE_SCREENSHOT) {
  if (requestScreenCapture(false)) {
    var img = captureScreen();
    console.log("capture:", img.getWidth(), img.getHeight());
    img.recycle();
  } else {
    console.warn("screen capture denied");
  }
}
```

## 接手要求

- 没有设备信息、权限状态和最小复现脚本时, 不把问题升级为 A 类直接修复。
- 涉及坐标映射的修复必须覆盖竖屏、横屏、不同分辨率和 Root/无障碍两条路径。
- 涉及截图的修复必须覆盖主 app 与 inrt 打包 APK。
- 目标 App 风控、控件不暴露、ROM 后台限制属于外部限制时, 优先补诊断和 fallback, 不承诺代码层完全修复。
