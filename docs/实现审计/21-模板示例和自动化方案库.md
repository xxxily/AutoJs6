# 模板示例和自动化方案库

> 日期: 2026-06-10
> 对应任务: T66 / A16
> 范围: 自动化方案库数据、AI 检索优先级、内置文档/示例、外部文档同步

## 实现范围

- 新增 `assets-app/solutions/automation-solutions.json`, 作为用户和 AI 共同使用的结构化方案库数据源。
- 方案库覆盖 8 类 A16 要求场景: App 启动与等待、列表滚动查找、表单填写、OCR 文字点击、截图找图、定时任务、Shizuku 应用管理、插件 OCR。
- 每个方案包含场景说明、依赖能力、风险等级、首选 API、文档入口、标签、常见失败原因、完整脚本、可复制模板和可选 `projectJson` 提示。
- `AiCapabilityIndex` 加载方案库并把 `solutions` 模块结果加权, 中文查询会按同义词键做包含式扩展, 让“列表滚动查找”“表单填写”“插件 OCR”“Shizuku 应用管理”等场景优先命中方案模式。
- `AiPromptBuilder` 在 system prompt 和 output rules 中要求复杂任务先复用方案库模板, 再补 API 文档; 方案库条目标注为 `Automation solution pattern`。

## 用户可见入口

- 内置文档: `app/src/main/assets-app/docs/automation-solutions.html`
- 内置文档聚合: `docs/sidebar.html`, `docs/all.html`
- 内置索引: `app/src/main/assets-app/indices/all.json` 中新增 `automationSolutions`
- 内置示例: `app/src/main/assets-app/sample/方案库/自动化方案库模板入口 [v6.7.3+].js`
- README: 脚本开发辅助章节说明自动化方案库和 AI 优先复用行为
- 外部文档仓库: `api/automationSolutions.md`, `api/aiScriptAssistant.md`, `api/sidebar.md`, `api/toc.md`, `api/all.md`, `api/progress.md`, `api/changelog.md`

## 验收覆盖

- 方案库解析测试: 校验 8 个方案全部可解析, 每个条目带 `Scenario`、`Capabilities` 和可复制模板。
- 检索优先级测试: 校验列表滚动、表单填写、插件 OCR、Shizuku 应用管理查询优先返回 `solutions.*`。
- Prompt 测试: 校验方案库条目标注为 `Automation solution pattern`, 普通 API 条目标注为 `API documentation`, 并要求先选择最近方案。
- 索引一致性测试: 校验 `indices/all.json` 新增 URL 均指向存在的 `automation-solutions.html` 锚点。
- JSON 语法校验: `indices/all.json`, `solutions/automation-solutions.json`, 外部 `runtimeApiIndexData.json`。

## 风险与后续

- 方案库模板是场景起点, 仍需用户按目标 App 的真实文案、控件 id、图片资源和授权状态改写。
- 内置示例默认只打印模板, 不直接执行点击、截图、定时任务或 Shizuku 操作, 以避免误触高风险动作。
- AI 检索加权能优先返回方案模式, 但最终生成质量仍取决于用户需求描述、上下文摘要和服务商模型能力。
- 真机未连接时无法验证应用内文档侧栏点击、示例树展示和复制模板的完整 UI 路径, 需后续在设备上补测。
