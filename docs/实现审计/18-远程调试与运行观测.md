# 18. 远程调试与运行观测审计

> 更新时间: 2026-06-09
> 对应任务: T63 / A11 远程调试、DevTools 与日志观测

## 覆盖范围

- 运行观测模型: `ScriptObservability` 记录 `executionId`、脚本路径、线程、状态、起止时间、异常、日志、能力调用事件和资源快照。
- 采集接入: `AutoJs` 注册全局脚本执行监听, `GlobalConsole.println` 写入运行日志, `ProjectCapabilityAuditLog.record` 同步写入能力事件。
- 远程调试桥: `RemoteDebugBridge` 通过现有 JSON Socket 命令通道返回 `debug_response`, 支持运行列表、运行快照、日志、诊断导出、停止/停止全部、文件脚本重启、脱敏 UI 快照和截图状态。
- 编辑器入口: `EditorView.showRunDetailsDialog()` 展示最近运行、异常堆栈、能力调用、日志摘要、资源占用和诊断 JSON 复制入口。
- 安全开关: 远程调试桥默认关闭; 抽屉“服务端模式”管理入口本地确认启用, token 仅创建/轮换时显示并复制, 本地只保存 SHA-256。

## 远程命令

除 `debug.status` 外, 命令都必须携带 `token` 或 `debugToken`:

- `debug.listRuns` / `debug.recentRuns`
- `debug.running`
- `debug.snapshot`
- `debug.logs`
- `debug.exportDiagnostics`
- `debug.stop`
- `debug.stopAll`
- `debug.restartLast` / `debug.restart`
- `debug.uiSnapshot`
- `debug.screenshot`

响应类型为 `debug_response`, 响应对象包含 `version`、`requestId`、`command`、`ok`、`timestamp`、错误 `code/message` 和 `payload`。

## 风险与后续

- 当前最小变量可见能力提供变量不可用原因、线程信息和异常/线程堆栈; Rhino 局部变量与断点协议需在后续 VSCode Debug Adapter 阶段扩展。
- 截图远程拉取当前返回结构化不可用状态, 避免远程命令静默触发系统录屏授权; 后续可在已有截图 Session 上导出缩略图或临时文件 URI。
- UI 快照依赖无障碍服务, 不可用时返回 `accessibility_service_unavailable`。
