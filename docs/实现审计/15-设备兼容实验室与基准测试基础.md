# 设备兼容实验室与基准测试基础

> 对应任务: T53 / A15
> 更新时间: 2026-06-09 02:25 CST

## 1. 测试分层

| 层级 | 当前入口 | 覆盖目标 | 执行方式 |
|---|---|---|---|
| JVM 单元测试 | `app/src/test/java` | 索引校验、ProjectConfig、能力映射、AI result parser、任务调度策略 | `:app:testAppDebugUnitTest` 或指定 `--tests` |
| Instrumentation smoke | `app/src/androidTest/java/org/autojs/autojs/compat/DeviceCompatibilitySmokeTest.kt` | 设备环境可加载核心能力注册表和调度策略 | `:app:connectedAppDebugAndroidTest` |
| 设备手工/自动矩阵 | 本文第 2 节 | Android 8-16、ROM、分辨率、方向、多窗口、权限流程 | 每次发布前按模板填写 |
| 基准记录 | 本文第 3 节 | 截图、OCR、选择器、定时任务、Shizuku 趋势 | 每轮设备验证追加记录 |

当前 P0 JVM 覆盖:

- 索引校验: `AiCapabilityIndexConsistencyTest`
- ProjectConfig: `ProjectConfigTest`
- 能力映射: `CapabilityRegistryTest`
- AI result parser: `AiResultParserTest`
- 任务策略: `TimedTaskSchedulingPolicyTest`

## 3. 基准指标记录模板

每次基准至少记录设备、版本、样本数、P50/P95、失败率和备注。

| 日期 | App commit | 设备/ROM | 指标 | 样本数 | P50 | P95 | 失败率 | 环境/备注 |
|---|---|---|---|---:|---:|---:|---:|---|
| YYYY-MM-DD |  |  | 截图首帧耗时 ms | 30 |  |  |  | 首次授权后冷启动 |
| YYYY-MM-DD |  |  | 截图连续帧间隔 ms | 120 |  |  |  | 目标 5/10/15 FPS 分档 |
| YYYY-MM-DD |  |  | OCR 耗时 ms | 30 |  |  |  | MLKit/RapidOCR/插件 OCR 分开记录 |
| YYYY-MM-DD |  |  | OCR 准确率 % | 30 |  |  |  | 固定截图样本集 |
| YYYY-MM-DD |  |  | 选择器查找耗时 ms | 100 |  |  |  | text/id/desc/className 各一组 |
| YYYY-MM-DD |  |  | 定时任务触发偏差 ms | 20 |  |  |  | 前台/后台/息屏/电池优化分别记录 |
| YYYY-MM-DD |  |  | Shizuku 绑定耗时 ms | 20 |  |  |  | 冷/热启动分开记录 |
| YYYY-MM-DD |  |  | Shizuku 调用耗时 ms | 50 |  |  |  | package/settings/input 首批 API |

趋势判定:

- `pass`: P95 无明显退化, 失败率低于上一稳定版本或可解释。
- `warn`: P95 退化 20%-50%, 或失败率上升但有规避方案。
- `fail`: P95 退化超过 50%, 或核心能力失败率不可接受。

## 4. 可控 UI 回归样例设计

后续建议新增 `app/src/androidTest` 专用 Activity 或独立 sample app, 不进入普通用户入口。

建议 Activity: `org.autojs.autojs.compat.CompatLabActivity`

页面区域:

- 固定文本区: `text/id/desc/className` 选择器基准。
- 表单区: EditText、CheckBox、Switch、RadioButton、Spinner。
- 列表区: 100/1000 项 RecyclerView, 支持滚动查找和动态插入/删除。
- 弹窗区: AlertDialog、BottomSheet、PopupWindow。
- 动态内容区: 倒计时、进度条、延迟加载文本。
- 隐私样例区: 手机号、邮箱、密码输入框, 用于后续 UI 树脱敏验证。

后续落地入口:

- Activity 文件: `app/src/androidTest/java/org/autojs/autojs/compat/CompatLabActivity.kt` 或 `app/src/debug/java/org/autojs/autojs/compat/CompatLabActivity.kt`。
- 测试文件: `app/src/androidTest/java/org/autojs/autojs/compat/CompatLabAutomationTest.kt`。
- 固定脚本样例: `app/src/main/assets-app/sample/兼容实验室/`。
- 基准输出: `build/reports/compat-lab/<device>/<date>.json`。
