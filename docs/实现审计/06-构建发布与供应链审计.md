## 范围

本分册覆盖 Gradle 配置、build-logic、native 包部署、CI、签名、wrapper、仓库解析、发布产物和版本写回。主要路径为:

- `settings.gradle.kts`
- `build.gradle.kts`
- `app/build.gradle.kts`
- `build-logic/**`
- `gradle/**`
- `.github/workflows/android.yml`
- `libs/**/build.gradle*`
- `sign.properties`
- `version.properties`

## 已确认未发现明确实现级问题的关键文件

- `gradle/libs.versions.toml`: 本轮未发现明显动态版本通配符问题; 风险主要来自仓库解析和 wrapper checksum。
- `gradle/data/*.properties` 与 `gradle/data/*.list`: 作为版本兼容数据可读性较好; 需要补 provenance, 已在 BUILD-15 记录。
- `.github/FUNDING.yml`: 与构建供应链无直接执行风险。
- `.gitattributes` 与 `.gitignore`: `sign.properties` 已忽略, 但本地存在真实口令的问题仍需按 BUILD-01 处理。
- `build-logic/convention/src/main/kotlin/org/autojs/build/UtilsPlugin.kt`: 主要暴露工具方法, 风险点已归并到 CRC32/LibDeployer/Versions。

## 后续验证建议

- 引入 Gradle dependency verification, 为外部依赖和 Gradle wrapper 固定 SHA-256。
- release CI 增加三道门: signing secret 必须存在、`apksigner verify` 必须通过、证书指纹必须匹配预期。
- remote native 包维护 `third_party_checksums.toml`, 每次下载后校验并输出 SBOM。
- 对 `.github/workflows/android.yml` 固定 action commit SHA 并设置最小权限。
